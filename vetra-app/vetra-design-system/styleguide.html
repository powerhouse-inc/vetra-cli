Override map — how to retheme
File to edit: vetra-app/style.css — @theme {} block + :root {} override

Components use hardcoded Tailwind classes. Three levers:

[1] Palette override — redefine gray-* in @theme {} → shifts all components at once
  e.g. --color-gray-50: hsl(220 20% 98%); → cool tinted backgrounds

[2] Semantic token override — :root { --background: ...; --primary: ...; } → shadcn components only

[3] Component class edits — change bg-white → bg-slate-900 etc. in the TSX files
  Key files: VetraStudio.tsx, ChatPane.tsx, PhaseCycle.tsx, BuildSection.tsx, Breadcrumb.tsx
