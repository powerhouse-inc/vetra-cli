# DEP.04 Answer status questions

Use this when the user asks about state instead of asking to deploy. Answer from
the tools, not memory.

- **"Published?"** — `reactor-project-publish-status` (with the env's
  `--registry`, optional `--version`): reports published / not / unknown, plus
  the latest published version.
- **"Installed in the env?"** — `deploy-environment-get --name <env> --filter
  $.packages` lists installed packages (name + version).
- **"Ready / what status?"** — `deploy-environment-get --name <env>` shows status,
  services, and host. For an in-progress deploy, prefer `deploy-environment-wait`
  over repeated reads.
- **"Built?"** — there's no build-status store. Run `reactor-project-check` (and
  `reactor-project-build` if needed) to verify it builds now; don't claim a prior
  build is still valid after edits.
