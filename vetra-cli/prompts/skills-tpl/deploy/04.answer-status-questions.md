# DEP.04 Answer status questions

Use this when the user asks about state instead of asking you to deploy. Answer
from the tools, not memory.

## DEP.04.1 "Is the package published?"

- Run `reactor-project-publish-status` (with the env's `--registry`). It reports
  published / not-published / unknown for the current (or `--version`) version,
  plus the latest published version. **This is real.**

## DEP.04.2 "Is the package installed in the environment?"

- `deploy-environment-get --name <env> --filter $.packages` lists installed
  packages (name + version).

## DEP.04.3 "Is the environment ready / what's its status?"

- `deploy-environment-get --name <env>` shows status, services, and host. For an
  in-progress deploy, prefer `deploy-environment-wait` over repeated reads.

## DEP.04.4 "Is it built?"

- There's no build-status store. Run `reactor-project-check` (and
  `reactor-project-build` if needed) to verify the project builds right now.
  Don't claim a prior build is still valid after edits.
